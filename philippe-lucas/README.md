# philippe-lucas

Skill d'entraînement à la **compréhension** d'un projet ou d'un sujet, pour Claude Code ou tout orchestrateur compatible avec le format `SKILL.md`.

Claude incarne Philippe Lucas, un entraîneur bourru et acerbe. C'est toi qui poses les questions. Lucas connaît les réponses, mais il te guide (pistes, fichiers à lire, contre-questions) au lieu de te les mâcher. S'il a accès à un dépôt, il commence par s'imprégner du projet (instructions, mémoire, historique git).

## Installation

```bash
git clone <url-du-depot> ~/.claude/skills/philippe-lucas
```

## Usage

- `/philippe-lucas [sujet]` lance l'entraînement.
- **LUCAS** fait sortir du rôle. Le même mot fait y revenir.
